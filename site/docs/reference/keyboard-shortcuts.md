# Keyboard Shortcuts

On a Mac, use **Cmd** wherever this page says **Ctrl**.

Console shortcuts pause while a dialog (such as Settings or the song editor) or the theme editor is open, so they never clash with typing. **Esc** and **Ctrl + K** keep working.

## Console

| Shortcut | Action |
|----------|--------|
| **Ctrl + K** | Open or close [global search](../guides/quick-search.md) |
| **Ctrl + 1** to **Ctrl + 5** | Switch to the Songs, Scripture, Strong's, Media or Presentations tab |
| **Ctrl + Tab** / **Ctrl + Shift + Tab** | Next / previous library tab |
| **Ctrl + ,** | Open Settings |
| **Ctrl + C** or **Ctrl + .** | Clear: hide the text on screen, or bring it back |
| **Ctrl + L** | Logo: show the logo background, or go back to the content |
| **Ctrl + T** | Add the highlighted library item to the schedule |
| **Ctrl + S** | Save the schedule (asks for a name if it hasn't got one) |
| **Ctrl + Shift + S** | Save the schedule under a new name |
| **Esc** | Close the open dialog, or clear the schedule selection |

If you hide the Strong's tab, **Ctrl + 3** to **Ctrl + 5** become Media, Presentations and Themes.

!!! warning "Ctrl + C clears the screen"
    **Ctrl + C** toggles Clear, even while you're typing in a library search box. Use the copy button to copy a verse.

## Moving through content

The arrow keys and **Enter** act on whichever area you clicked last: the library, Preview or Live. See [Interface Overview](../getting-started/interface-overview.md#which-panel-do-the-arrow-keys-control).

| Shortcut | In the library | In Preview | In Live |
|----------|----------------|------------|---------|
| **Up** / **Down** | Move through the list, loading each item into Preview | Select the previous / next slide | Show the previous / next slide on screen |
| **Enter** | Send the highlighted item live | Send the selected slide live | |
| **Ctrl + Up** / **Ctrl + Down** | | | Line up a slide without showing it. Let go of **Ctrl** to show it. |

## Schedule

| Shortcut | Action |
|----------|--------|
| **Ctrl + click** | Add a row to the selection |
| **Shift + click** | Select a range of rows |
| **Delete** | Remove the selected rows (after Ctrl + click, Shift + click or right-click) |
| **Esc** | Clear the selection |
| Double-click | Send the row live |

## Scripture tab

| Shortcut | Action |
|----------|--------|
| **Ctrl + 2** | Open the Scripture tab |
| **Ctrl + F** | Switch between reference and full-text search |
| **Space** | After a short book name, complete it (`jn` becomes `John`) |
| **Shift + Up** / **Shift + Down** | Grow or shrink a multi-verse selection |
| **Shift + click** | Select a range of verses |
| **Ctrl + click** | Add or remove single verses |

## Media tab

| Shortcut | Action |
|----------|--------|
| Arrow keys | Move between tiles in grid view |
| **Ctrl + click** / **Shift + click** | Select several items |

## Global search (Ctrl + K)

| Shortcut | Action |
|----------|--------|
| **Up** / **Down** | Move through results |
| **Tab** / **Shift + Tab** | Pick a different section of the highlighted song |
| **Enter** | Run the default action for that kind of result |
| **Ctrl + Enter** | Go Live |
| **Shift + Enter** | Add to Schedule |
| **Esc** | Close |

## Song editor

| Shortcut | Action |
|----------|--------|
| **Ctrl + S** | Save the song |
| **Ctrl + Z** | Undo |
| **Ctrl + Y** or **Ctrl + Shift + Z** | Redo |
| **Ctrl + M** | Switch between Structured and Raw text views |
| **Ctrl + B** / **Ctrl + I** / **Ctrl + U** | Bold / italic / underline the selected lyrics |
| **Ctrl + V** | Paste, keeping bold, italic and underline |
| **Ctrl + Shift + V** | Paste as plain text |
| **Enter** in the title | Save |
| **Esc** | Close the editor |

In the schedule item editor, **Ctrl + S** saves to the schedule.

## Media crop

In a picture or video's **Edit…** dialog, after clicking the crop area:

| Shortcut | Action |
|----------|--------|
| Arrow keys | Move the crop box (**Shift** for small steps) |
| **Ctrl** + arrow keys | Resize the crop box |
| **Shift** while dragging a corner | Crop to any shape instead of 16:9 |

## Theme editor

| Shortcut | Action |
|----------|--------|
| **Ctrl + S** | Save the theme and close the editor |
| **Ctrl + Z** | Undo |
| **Ctrl + Y** or **Ctrl + Shift + Z** | Redo |
| **Ctrl + D** | Duplicate the selected layer |
| **Delete** | Delete the selected layer |
| Arrow keys | Nudge the selected layer 1% (**Shift** for 5%) |
| **Ctrl + 0** | Reset zoom to 100% |
| **Esc** | Deselect. With nothing selected, close the editor. |
| **Shift** while rotating | Snap to 15° steps |
| **Shift** while skewing | Skew in one direction only |
| **Alt** while pointing at a layer | Measure the gap to the selected layer |

Arrow keys, Delete and undo don't affect the canvas while you're typing in a text field.

## Projection and output windows

| Shortcut | Action |
|----------|--------|
| **Esc** in the projection window | End Live (close the projection window) |
| **Esc** in an extra output window | Switch that output off |
