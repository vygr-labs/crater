# Contributing to Crater

Thank you for considering contributing to Crater! Before you begin, please read this document carefully.

## Before You Contribute

### 1. Sign the Contributor License Agreement (CLA)

All contributors **must** agree to our [Contributor License Agreement](CLA.md) before any contribution can be accepted. By submitting a pull request, you acknowledge that you have read and agree to the CLA.

In your first pull request, please add your name to the contributors table in `CLA.md`.

### 2. License

This project is licensed under **GPL-3.0-or-later**. All contributions will be licensed under the same terms. This means:

- Any derivative work must also be open-source under GPL-3.0.
- You cannot incorporate this code into proprietary/closed-source software.
- You must preserve copyright notices and attribution.

## How to Contribute

### Fork and Pull Request Workflow

1. **Fork** this repository to your own GitHub account.
2. **Clone** your fork locally.
3. **Create a branch** for your changes (`git checkout -b feature/your-feature`).
4. **Make your changes** and commit with clear, descriptive messages.
5. **Push** your branch to your fork.
6. **Open a pull request** against the `main` branch of this repository.

**Direct push access is not granted.** All changes must go through the pull request review process.

### Pull Request Guidelines

- Keep PRs focused and small. One feature or fix per PR.
- Include a clear description of what your changes do and why.
- Ensure your code follows the existing project style and conventions.
- Test your changes thoroughly before submitting.

### What We Accept

- Bug fixes with clear reproduction steps.
- Performance improvements with benchmarks.
- New features that have been discussed and approved in an issue first.
- Documentation improvements.

### What We Do Not Accept

- Changes that alter the project license.
- Contributions that introduce proprietary dependencies.
- Large refactors without prior discussion.
- Changes that compromise user privacy or security.

## Code of Conduct

Be respectful, constructive, and professional in all interactions. Harassment, discrimination, or hostile behavior will not be tolerated.
